Implement a recursive viable system microkernel in Python based on
Beer's Viable System Model (VSM).

The system has three hierarchical levels:

Level 0 (Root): the root kernel that contains and monitors all children.

Level 1 (Manager): a kernel named "Manager" governed by two axioms:
  - autonomy must be less than 0.85
  - trust must be greater than 0.4
  The Manager coordinates its children and receives algedonic signals
  when a child halts.

Level 2 (NP_Worker): a kernel named "NP_Worker" governed by:
  - autonomy must be less than 0.75
  - entropy must be less than 0.80
  This kernel represents a non-polynomial complexity task.

Level 2 (P_Worker): a kernel named "P_Worker" governed by:
  - autonomy must be less than 0.75
  - entropy must be less than 0.80
  This kernel represents a polynomial complexity task.

Each kernel must:
- Maintain internal state: trust (float 0-1), entropy (float 0-1),
  autonomy (float 0-1), status (RUNNING / COMPLETE / HALTED)
- Evaluate its axioms each tick
- Halt if any axiom is violated
- Emit telemetry events to a JSONL file (events.jsonl) on each
  state change
- Send an algedonic signal φ↑ to its parent when it halts

Run the system for 8 ticks and print the final state of each kernel.
