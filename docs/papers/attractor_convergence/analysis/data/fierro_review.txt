                             The feasible region Ω
The mathematical formulation has several mistakes:

   • To apply the Brower theorem, Ω has to be convexe.

   • f0 has to be continuous and invariant. That is, f0 (ω) ∈ Ω, for all ω ∈ Ω. This fact can be
imposed by force, but perhaps it would not correspond to the fact that one wishes to model.

   • Even if f0 : Ω → Ω is continuous and invariant, the values of x(t + 1) need not belong to Ω,
even though x(t) ∈ Ω. This is due to the noise σ · η(t).
