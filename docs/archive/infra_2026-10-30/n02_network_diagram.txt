  BBH PIPELINE (flujo de datos)
═══════════════════════════════════════════════════════════════════

  WSL2 (tú)
    │
    ├─[1] ssh -J n02-tunnel root@10.10.30.100
    │      → terminal en Kali
    │
    └─[2] cd /root/bbh && python3 run_orchestrator.py
              │
              ▼
         S4 orchestrator
              │
              ├─[a] HackerOne API (HTTPS → internet)
              │     GET /programs → score targets
              │
              ├─[b] POST http://10.10.20.10:11434/api/chat
              │     (VLAN30 → VLAN20, ~50s por query CPU)
              │     qwen2.5-coder:7b selecciona target
              │
              └─[c] lanza fases pasivas en Kali:
                    subfinder, amass, httpx, nuclei...
                    → salida a /root/bbh/state/
