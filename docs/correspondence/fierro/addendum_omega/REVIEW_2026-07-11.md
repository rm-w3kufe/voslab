## F1 — "Spherical cap … compact and convex" is imprecise, and the argument can be made convexity-free (STRONGEST FIX)

**Problem.** A spherical cap (a cap ON a sphere) is not convex in the ambient
space. The set actually intended, `{x : cos(x,s) ≥ θ_A}`, is a circular
(Lorentz-type) **cone** — convex for θ_A ≥ 0 — but unbounded, so compactness
needs the intersection with the bounded state polytope. As written, a careful
reader gets a contradiction ("cap" + "convex") before reaching the intended
object. Moreover the cover letter says "Krasnoselskii sobre el **politopo**"
while the addendum says "spherical cap" — the two documents disagree on the
geometry of the same object.

**Deeper opportunity.** The corrected argument can drop the convexity
load-bearing entirely:

- **Deterministic fixed point**: Banach contraction on Ω_A needs only
  completeness + invariance f₀(Ω_A) ⊆ Ω_A + measured L < 1. No convexity.
- **Existence of invariant measure**: Krylov–Bogolyubov needs only a Feller
  chain on a compact state space (f₀ continuous, additive noise ⇒ Feller;
  state space compact by construction). No convexity.
- **Uniqueness + rate**: Foster–Lyapunov drift (Meyn–Tweedie), already cited.

This turns the answer to Q1 from "we found a convex sub-region" into **"you
are right, and the corrected argument no longer requires convexity anywhere"**
— strictly stronger, and immune to any further probing of Ω_A's geometry.
Krasnosel'skiĭ remains citable for the deterministic sum-form if desired, but
stops being the pillar.

**Proposed replacement for §1 Resolution:**

> *Resolution.* We no longer route existence through convexity. The corrected
> argument has three independent legs: (i) the state space is a compact
> polytope and the update kernel is Feller (continuous f₀, additive noise), so
> an invariant probability measure exists by Krylov–Bogolyubov; (ii) on the
> contractive core Ω_A = {x ∈ Ω : ⟨x,s⟩ ≥ θ_A‖x‖‖s‖} — the intersection of a
> convex cone with the state polytope — the measured contraction
> (λ_max = ln 0.99 < 0, EXP-LY-01) gives a unique deterministic fixed point by
> the Banach principle, no convexity required; (iii) uniqueness and geometric
> convergence of the invariant measure follow from the Foster–Lyapunov drift
> condition of §3 (Meyn & Tweedie [2009]). Brouwer is not invoked at any
> point, and no step depends on the convexity of Ω or of Ω_A.

(If the polytope claim needs hedging: the occupation block is a simplex and
the remaining blocks are norm-bounded; "compact convex state polytope" can be
softened to "compact state set" — Krylov–Bogolyubov does not care.)

**Also update** the paper's Theorem 1 (hybrid invariance) wording in the same
direction, and align the cover letter ("politopo") with whichever formulation
ships.

## F2 — "A₀ removes a half-space" undermines the non-convexity claim

Removing a half-space from a convex set means intersecting with the
complementary half-space — which **preserves** convexity. If A₀'s exclusion is
genuinely non-convex (a hash-validity predicate is not even a geometric
region), don't call it a half-space; if it is a half-space, it is not a
culprit of non-convexity and should be dropped from that sentence. Proposed:

> "…the entropy bound H(x) ≤ H_max is an upper level set of a concave function
> (non-convex in general), and the ethical exclusion A₀ is a non-geometric
> predicate (covenant-hash validity) that need not preserve convexity."

## F3 — Non-expansiveness on Ω \ Ω_A is asserted, not discharged

### Formula

From `SplitOperator::lipschitz_bound` (operator.rs:231-248):

```
L_f(τ) = max_s ||∇logit_s|| · diam_modes / τ
```

Where:
- `||∇logit_s||` = L₂ norm of logit gradient for mode s (weight vector)
- `diam_modes` = max pairwise Euclidean distance between mode centers μ_s
- `τ` = softmax temperature (adaptive by lifecycle phase)

### Verdict

**L_f > 1 for ALL lifecycle phases.** The claim in Thm 1 that `L <= 1 (non-expansive) on
Omega\Ω_A` is **NOT discharged** from the deployed kernel constants.

**Recommendation:** Replace the non-expansive claim with `τ_rec = 1/L_max` as the effective
contract. For production (τ=0.05), `τ_rec = 1/24.418 = 0.041` — the closest `τ_rec` for
the tightest bound (onboarding, τ=0.85) would be `τ_rec = 1/1.436 = 0.696`.

The Lipschitz bound is dominated by the temperature denominator: at τ=0.05 (production,
sharp policy), L_f = **24.4**. This is expected behavior — low temperature amplifies the
policy gradient. The theory should cite `τ_rec` as the empirical contract instead of
asserting L ≤ 1 unconditionally.
