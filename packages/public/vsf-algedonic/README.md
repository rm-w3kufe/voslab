# vsf-algedonic

Scripts algedonic del sistema VSF.

## Instalación

```bash
pip install vsf-algedonic
```

## Uso

```python
from vsf_algedonic import ac_algedonic, ac_classifier

# Ejecutar scripts algedonic
```
